# Audio Path and Wideband FM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every audio stream the node emits is 48 kHz; broadcast FM, AM and SSB can be listened to and are named correctly: layer 1 says `wfm` (with the 19 kHz pilot as evidence) and layer 2 says "FM Broadcast Radio" from a signal catalogue.

**Architecture:** A streaming rational resampler in `zeta-dsp` replaces the integer-only audio decimator, so demodulators output a fixed `audio_rate_hz` whatever the channel rate. Three new stages (`wfm_demod`, `am_demod`, `ssb_demod`) and job kinds reuse the channel stage and the resampler. The layer-1 rule set gains a wideband-FM rule with a pilot-tone check. A catalogue knowledge provider (594 signals from iNTERCEPT's Apache-2.0 `signals.json`) feeds both `knowledge_lookup` and a new layer-2 classifier that ranks catalogue entries against the measured band, bandwidth and layer-1 label; the `Classifier` trait gains the block centre it needs. The UI gets the new decode entries and plays any audio-producing job.

**Tech Stack:** Rust 2024 (`zeta-dsp`, `zeta-core`, `zeta`, `zeta-ui`), existing `rustfft`-based helpers, vanilla JS, Playwright scenarios.

**Spec:** `docs/superpowers/specs/2026-10-18-zetasdr-design.md` sections 4.3 (audio streams), 4.4 (knowledge providers), 4.5, 6.1 (layer 1: modulation), 6.2 (layer 2: known signal types, lookup identifiers).

## Global Constraints

- `zeta-core` gains no dependency (`no_privileged_deps` keeps passing); the catalogue data lives in `zeta-dsp`.
- Strict op schemas: every `Op::JobStart` field stays required; the one new field (`sideband`) is required-nullable with `deserialize_with = nullable_*` and `schema_with` like `deviation_hz`; MCP tools, AGENTS.md and SKILL.md regenerate and their drift checks pass.
- Audio streams are 48 kHz mono f32 in ±1 (`AUDIO_RATE_HZ = 48_000`); the only exception is APRS's internal 48 kHz path, which already matches.
- Layer-1 labels keep their vocabulary (`noise`, `carrier`, `fm`, `fsk`, `unknown`) and add `wfm`, `am`, `ssb`; the evidence string names the measurements the rule used.
- Layer-2 labels from the catalogue carry `confidence` from the match quality and `evidence` naming the catalogue id and the fields that matched; a non-match emits nothing (no "unknown" from layer 2).
- Licensing: the catalogue is copied with its Apache-2.0 notice (`data/NOTICE`); no GPL data (Artemis's DB is not used).
- CI runs on synthetic fixtures; no hardware.
- Gate: `cargo fmt --check`, `cargo clippy --workspace --all-targets --all-features -- -D warnings`, `cargo test --workspace --all-features`, `zeta agents-md --check`, `--skill --check`, `cargo test -p zeta --test ui -- --nocapture` with no skip line.

## Review Focus

1. A channel rate that is not an integer multiple of 48 kHz (200 kHz, 250 kHz, 1 Msps) must still give clean 48 kHz audio with no aliasing or drift across blocks. Test: Task 1 `resampler_keeps_a_tone_clean_across_blocks_at_200k_to_48k`.
2. An over-deviated or clipped FM signal must not produce NaN or full-scale noise; output stays within ±1. Test: Task 2 `wfm_demod_clamps_over_deviation`.
3. A real broadcast carrier with multipath has an envelope CV above the NBFM threshold; the `wfm` rule must accept it (looser CV) without stealing narrowband signals from `fm`. Test: Task 3 `nbfm_fixture_is_still_fm_not_wfm`.
4. A catalogue entry must not be claimed when the bandwidth is far off (a 12.5 kHz NBFM voice channel at 100 MHz is not "FM Broadcast Radio"). Test: Task 6 `catalogue_does_not_match_nbfm_in_the_broadcast_band`.
5. SSB with the wrong sideband selected must still produce bounded audio and the op must reject `sideband` on kinds that do not take it. Test: Task 5 `job_start_rejects_sideband_on_other_kinds`.

Conventions used by every task:

- `AUDIO_RATE_HZ = 48_000` is a `pub const` in `zeta-core::ops`, used by every expansion.
- Job expansion for the audio kinds: `channel` (centre, bandwidth, `out_rate_hz = channel_rate_hz(source_rate, bandwidth)`) → `<demod>` with `audio_rate_hz: AUDIO_RATE_HZ`; the demod stage resamples from its input rate to 48 kHz internally.
- `wfm_demod` params: `{deviation_hz: 75_000, audio_rate_hz, deemphasis_us: 50}` (`deemphasis_us` 50 or 75; Australia and Europe use 50). `am_demod` params: `{audio_rate_hz}`. `ssb_demod` params: `{sideband: "usb" | "lsb", audio_rate_hz, audio_bandwidth_hz: 2_800}`.
- `Op::JobStart` gains `sideband: Option<Sideband>` (enum `usb`/`lsb`, snake_case), required-nullable: `null` means `usb` for `ssb_demod` and must be `null` for every other kind (error `other` naming the kind, like `deviation_hz`). CLI `--sideband usb|lsb`.
- Layer-1 constants: `WFM_MIN_BW_HZ = 100_000`, `WFM_MAX_BW_HZ = 250_000`, `WFM_MAX_CV = 0.35`, `WFM_MIN_DEV_HZ = 5_000`, `PILOT_HZ = 19_000`, `PILOT_TOL_HZ = 300`, `LINE_DB = 10` (reuse the existing line constant if one exists with that meaning). AM: `AM_MIN_CV = 0.25` and a carrier line at the band centre at least `OCCUPIED_DB` above the sidebands. SSB: no carrier line, envelope CV above `AM_MIN_CV`, occupied band 1.5–4 kHz, energy on one side of centre only.
- Catalogue match score: `+0.4` if a `frequency_ranges` entry contains the measured `center_hz`; `+0.3` if `bandwidth_hz` lies within `[0.5 × bandwidth_range.min_hz, 1.5 × bandwidth_range.max_hz]`; `+0.3` if the layer-1 label maps to one of the entry's `modulations` (`wfm → WFM|FM`, `fm → FM|NFM|NBFM`, `am → AM`, `ssb → SSB|USB|LSB`, `fsk → FSK|AFSK|GFSK|2-FSK`, `carrier → CW`); a result needs the frequency match and at least one more, and when the entry's `bandwidth_range.max_hz` is above 50 kHz the bandwidth match is required (a narrowband voice channel inside the broadcast band is not a broadcast station); `confidence = score`, at most 3 labels, highest first; `evidence` = `"catalogue <id>: freq <in range>, bandwidth <ok|off>, modulation <ok|n/a>"`.
- `Classifier::classify(&self, iq, sample_rate_hz, center_hz: Hz, band, features)`: `center_hz` is the block's RF centre; `run_all` passes it; every implementer updated.
- Fixtures (`zeta-dsp::fixtures`): `wfm_modulate(audio, audio_rate_hz, iq_rate_hz, deviation_hz, offset_hz, pilot: bool)` = `nbfm_modulate` with a 19 kHz pilot at 0.1 added to `audio` when `pilot` (audio rate must be ≥ 48 kHz); `am_modulate(audio, audio_rate_hz, iq_rate_hz, modulation_index, offset_hz)`; `ssb_modulate(audio, audio_rate_hz, iq_rate_hz, usb: bool, offset_hz)` (Hilbert via FFT).
