# ZetaSDR DSP Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Real signal work on the core node: channelise, demodulate NBFM to audio, decode AFSK1200/APRS to events, measure layer-1 features, and prove the CPU/GPU stage boundary with an FFT stage, all driveable as job kinds and visible through the CLI.

**Architecture:** A new plugin crate `zeta-dsp` holds every stage and pure DSP function and registers them into the core's `StageRegistry`; `zeta-core` stays free of DSP dependencies. Job kinds in the core expand to graphs of these stages by name only. Synthetic modulators in `zeta-dsp`'s test fixtures generate NBFM and APRS signals so every decoder is proven by round trip with no hardware. Two preparatory refactors from plan 1's final review (split `node.rs`, version persisted records) land first.

**Tech Stack:** Rust 1.97, `rustfft` (CPU FFT), `wgpu` + `bytemuck` + `pollster` behind a `gpu` feature (GPU FFT), existing tokio/serde/schemars stack. No GNU Radio, SoapySDR or model client anywhere.

**Spec:** `docs/superpowers/specs/2026-10-18-zetasdr-design.md` (sections 4.3, 4.5, 4.6, 5.1, 6.1, 6.2, 8)

## Global Constraints

- `zeta-core` must not depend on any SDR driver, DSP framework, GUI toolkit or LLM client crate; the existing `no_privileged_deps` test gains `rustfft` and `wgpu` in its banned list. DSP lives in `zeta-dsp` (design: no privileged backend; GNU Radio is one stage host among several).
- Every frequency, bandwidth and rate field is an integer named `*_hz` or `*_baud`; time fields end in `_ns`; enums on the wire are snake_case (plan 1 vocabulary; design 5.1).
- Stage params schemas: `additionalProperties: false`, every field required (design 5.1); the existing `nested_schemas_are_strict` test must keep passing for every new `Op` and `OpResult` variant.
- A stage returns `Err(StageError::Cancelled)` on cancellation, `Ok(())` when its input closes, `Err(StageError::Failed(msg))` for everything else; `Failed` messages name the offending field and value (plan 1 stage contract).
- A stage with CPU and GPU implementations must produce the same result from either (design 4.6: "identical semantics"); the scheduler picks by availability, and absence of a GPU never fails a job.
- Output frames carry provenance whose `span` is the time range of the samples in the frame; `channel` is `Some(ChannelId)` for channelised outputs (design 4.3).
- Layer-1 output is a `FeatureRecord` with numbers; labels are secondary (design 6.1). Layer 2 reports decode-to-identify evidence (design 6.2). Unknown is reported as unknown, never guessed (AGENTS.md rule).
- `cargo fmt --check`, `cargo clippy --workspace --all-targets -- -D warnings` and `cargo test --workspace` pass with no hardware; GPU tests skip (not fail) without an adapter.
- Build the minimum (ponytail): reuse before stdlib before dependency before new code.

## Review Focus

1. NBFM demod on a channel containing only noise must emit bounded audio with no NaN or infinite samples, not a scream or a crash. Test in Task 7.
2. The APRS decoder fed a packet with one flipped bit must emit nothing, not a corrupted frame (CRC gate; design 6.2 "see whose CRC passes"). Test in Task 8.
3. A channel request whose band lies outside the incoming block's band must fail the stage with a message naming `center_hz` and the block's range, not silently produce aliased samples. Test in Task 5.
4. An FFT size that is not a power of two must be rejected by graph validation before anything runs. Test in Task 6.
5. A `spectrum` job on a node whose `backends` list lacks `Gpu` must run on CPU with identical output; `select` never returns `None` for `fft` when CPU is available. Test in Task 6 and Task 13.
6. `measure` on pure noise must report `burst: false`, `snr_db` below 3 and `symbol_rate_baud: None`, and the layer-1 classifier must label it `noise`, never a modulation. Test in Task 10.

### Task 8: AFSK1200, HDLC and AX.25 decoders

**Files:**
- Create: `crates/zeta-dsp/src/afsk.rs`, `crates/zeta-dsp/src/ax25.rs`
- Test: unit tests in both files

**Interfaces:**

### Task 10: Layer-1 measurement, `measure` stage and classifier

**Interfaces:**
- Produces: `pub fn measure(iq: &[Complex<f32>], rate_hz: u64, block_center_hz: u64) -> FeatureRecord` using `power_spectrum_db(.., 1024, Hann)`: noise floor = median bin; `snr_db` = peak − median; occupied band = the contiguous run of bins around the peak at or above floor + 6 dB → `bandwidth_hz` (run length × bin_hz, minimum one bin) and `center_hz` (block centre + offset of the run's centre); `burst` = ratio of max to mean envelope power over 10 ms chunks > 3.0; `symbol_rate_baud` = `Some(f)` for the strongest line in the DFT of the demeaned squared envelope between 50 Hz and rate/2 if it exceeds the median of that spectrum by 10 dB, else `None`.
- `pub fn layer1_label(f: &FeatureRecord, iq: &[Complex<f32>], rate_hz: u64) -> Label` (layer 1): `"noise"` 0.5 when `snr_db < 6`; `"fsk"` 0.6 when the power spectrum has two peaks within the occupied band separated by 500–3000 Hz and within 6 dB of each other; `"fm"` 0.6 when the envelope coefficient of variation < 0.2 and `bandwidth_hz ≤ 25_000`; otherwise `"unknown"` 0.5; `evidence` lists `snr_db`, `bandwidth_hz`, `symbol_rate_baud` and the CV with units.
- `MeasureStage` kind `"measure"`, inputs `[Iq]`, outputs `[Event]`, params `MeasureParams {}`; emits `Payload::Event(serde_json::to_value(FeatureRecord))` plus `"label": Label` per block.
- `Layer1Classifier` implementing `zeta_core::classify::Classifier` (`name "layer1-classical"`, `layer 1`) returning `vec![layer1_label(&measure(iq, rate, 0), ..)]`.
- `JobKind::Measure` → one `measure` node; wire `"measure"`.
