# Fonts

- `Comfortaa-VF.ttf`: Comfortaa by Johan Aakerlund (The Comfortaa Project Authors), the
  variable-weight TTF (Light to Bold, `wght` 300-700), `Comfortaa[wght].ttf` from google/fonts
  at commit 2fe1e8c, version 3.105 as its name table records. SIL Open Font License 1.1,
  `OFL-Comfortaa.txt` beside it.
- `Nunito-VF.ttf`: Nunito by Vernon Adams (The Nunito Project Authors), the variable-weight TTF
  (ExtraLight to Black, `wght` 200-1000), `Nunito[wght].ttf` from google/fonts at commit
  2fe1e8c, version 3.602 as its name table records. SIL Open Font License 1.1,
  `OFL-Nunito.txt` beside it.

Upstream ships TTF only and the build host has no woff2 compressor, so the TTFs ship as is.
