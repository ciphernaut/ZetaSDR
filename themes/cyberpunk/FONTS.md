# Fonts

- `Orbitron-VF.ttf`: Orbitron by Matt McInerney (The Orbitron Project Authors), the
  variable-weight TTF (Regular to Black, `wght` 400-900), `Orbitron[wght].ttf` from
  google/fonts at commit 2fe1e8c, version 2.001 as its name table records. SIL Open Font
  License 1.1, `OFL-Orbitron.txt` beside it.
- `ShareTechMono-Regular.ttf`: Share Tech Mono by Carrois Type Design (Ralph du Carrois), from
  google/fonts at commit 2fe1e8c, version 1.003 as its name table records. SIL Open Font
  License 1.1, `OFL-ShareTechMono.txt` beside it.

Upstream ships TTF only and the build host has no woff2 compressor, so the TTFs ship as is.
