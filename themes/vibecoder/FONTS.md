# Fonts

- `Inter-VF.ttf`: Inter by Rasmus Andersson (The Inter Project Authors), the variable upright
  TTF (`wght` 100-900, `opsz` 14-32), `Inter[opsz,wght].ttf` from google/fonts at commit
  2fe1e8c, version 4.001 as its name table records. SIL Open Font License 1.1,
  `OFL-Inter.txt` beside it.
- `JetBrainsMono-VF.ttf`: JetBrains Mono by Philipp Nurullin and Konstantin Bulenkov (The
  JetBrains Mono Project Authors), the variable-weight upright TTF (`wght` 100-800),
  `JetBrainsMono[wght].ttf` from google/fonts at commit 2fe1e8c, version 2.211 as its name
  table records (the same file the terminal theme carries). SIL Open Font License 1.1,
  `OFL-JetBrainsMono.txt` beside it.

Upstream ships TTF and the build host has no woff2 compressor, so the TTFs ship as is.
